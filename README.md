# Brewtopia Coffee — Vaishali Nagar, Jaipur

Scroll-driven 3D website for Brewtopia Coffee.

- `index.html` — the page
- `css/style.css` — styles
- `js/app.js` — scroll choreography + three.js cup / glass
- `js/three.min.js`, `js/gsap.min.js`, `js/ScrollTrigger.min.js` — libraries (bundled, no CDN needed)
- `assets/img`, `assets/video` — optimised photos and clips from the café's Instagram and Google Business Profile

Open `index.html` locally, or visit the GitHub Pages link.
